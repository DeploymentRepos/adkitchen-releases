# 0.4.0

- **The Kitchen has its own background service** — Claude Code sessions, conversations, AI oversight and the AI log now come from `adkd`, a small service that ships inside the app and starts with it. It records sessions through its own Claude Code hooks, so it works whether or not Stenographer is installed, and the two run side by side without touching each other's setup.
- **A gentle start** — the first import brings in the last 30 days of Claude Code history, and AI summaries and AI oversight start off until you turn them on.
- **Oversight sees context use** — AI oversight now knows how full each session's context window is.
- **AI plugins load from the Kitchen's own Plugins folder** — in its Application Support folder.
- **A clear message when the service is out of date** — if the background service is older than the app needs, the Kitchen says so and quits rather than misbehaving.
- **A clean uninstall** — uninstalling with Homebrew stops the service and removes its hooks; `zap` also removes its data and logs.
