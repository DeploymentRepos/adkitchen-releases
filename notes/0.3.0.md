# 0.3.0

- **No more password prompt at first launch** — after a pkg install, the app no longer asks for an administrator password to take ownership of itself, a step that failed on macOS 26 with a wall of "Operation not permitted" errors. If an update needs a password, the built-in updater asks for it.
- **Settings help per window** — each Settings window keeps its own help drawer open or closed, independent of the others.
- **Readable settings tables** — hover over a cut-off table cell to see its full text, and over a column header for what that column means.
